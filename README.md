# Shazaam Portfolio Website

A modern, responsive influencer portfolio website developed as part of a **Web Development Internship Selection Task**.

🌐 **Live Demo:** [shazaam-portfolio.vercel.app](https://shazaam-portfolio.vercel.app/)

📂 **GitHub Repository:** [SHAZAAM-PORTFOLIO](https://github.com/abhisheksuvarna782-coder/SHAZAAM-PORTFOLIO)

## 📌 About the Project

This project was developed as part of a practical assignment for a web development internship selection process. The objective was to design and develop a creative, visually appealing website for the influencer **Shazaam**, based on his online presence and content style.

The website focuses on modern UI/UX, visual presentation, responsiveness, and creating an engaging digital experience that reflects the influencer's personality and online identity.

## 🎯 Project Objectives

- Design a creative and attractive influencer portfolio website.
- Build a modern and responsive user interface.
- Apply frontend development concepts and component-based architecture.
- Create a smooth and engaging browsing experience.
- Deploy the website and make it accessible online.

## ✨ Key Features

- Modern and visually engaging user interface.
- Black-and-green visual theme.
- Responsive layouts for different screen sizes.
- Component-based frontend architecture.
- Integration with social media links.
- Fast development and production builds using Vite.
- Live deployment through Vercel.

## 🛠️ Technologies Used

- **React.js** — Component-based user interface development.
- **TypeScript** — Type-safe application development.
- **Vite** — Development server and production build tool.
- **CSS** — Styling, layouts, and responsive design.
- **Git & GitHub** — Version control and source code management.
- **Vercel** — Website deployment and hosting.

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js and npm installed on your system.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/abhisheksuvarna782-coder/SHAZAAM-PORTFOLIO.git
```

**2. Navigate to the project folder**

```bash
cd SHAZAAM-PORTFOLIO
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Create a production build**

```bash
npm run build
```

## 🌐 Deployment
